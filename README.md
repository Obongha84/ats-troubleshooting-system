# ATS - Automated Troubleshooting System

A web-based diagnostic and repair tool that solves the limitations of desktop-only tools like HDD Sentinel.

## Features
- Multi-user authentication
- Automated scheduled scans
- Email alerts for critical issues
- Historical diagnosis tracking
- PDF/CSV export
- AI-powered assistant chatbot
- Disk temperature monitoring

## Setup

1. Install Python 3.10+
2. Install dependencies:
   pip install -r requirements.txt
3. Run the app:
   python web_app.py
4. Open http://127.0.0.1:5000

## First Time Setup
- Register the first account — it automatically becomes admin
- Click "Run Diagnostics" to create your first scan
